# Kenney Car Kit Assets

The files in this directory are selected assets from Kenney Car Kit 3.1.

- Author and distributor: Kenney
- Source: https://kenney.nl/assets/car-kit

The original `License.txt` from the downloaded archive is included unchanged.
Only the GLB models and shared texture used by the semantic occupancy scene are
bundled. No runtime request is made to Kenney or another asset host.
